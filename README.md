# my-match3

这是一个消消乐（Match-3）Web 原型，采用扁平卡通风格的占位美术（SVG），实现了：

- 6x6 网格（可配置）
- 方块交换、3+ 匹配消除、下落补充、连锁
- 鼠标与触摸支持
- 简单分数与步数逻辑
- 关卡选择（不同 allowedTypes 与步数）
- 16 个 SVG 占位方块资源
- 基本音效（WebAudio 生成）

运行方法：
1. 克隆仓库或下载文件
2. 在仓库根目录打开 `index.html`（直接在浏览器打开即可）

文件列表：
- index.html
- style.css
- game.js
- assets/block-01.svg ... assets/block-16.svg
